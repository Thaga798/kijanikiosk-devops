# Week 2 - DevOps Starter Kit

## About This Week

For Week 2, I worked on a small DevOps Starter Kit for the KijaniKiosk project. The main goal was to understand some of the basic ideas behind DevOps and cloud infrastructure before working on a larger platform.

I focused on Git collaboration, cloud service models, regions and Availability Zones, IAM permissions, and basic network separation.

## Where the Work Is

I created a separate feature branch for this work:

`feature/starter-kit-files`

The work was then pushed to GitHub and submitted as Pull Request #7 to the `develop` branch.

**Pull Request:**
https://github.com/Thaga798/kijanikiosk-devops/pull/7

The Pull Request was left open so that the work can be reviewed.

## What I Worked On

The `starter-kit` folder contains the following files:

* **delivery-notes.md** - My notes on Flow, Feedback, and Learning in DevOps, together with my reflections on the work.
* **cloud-model.md** - My comparison of IaaS, PaaS, and SaaS and why I chose IaaS for the initial KijaniKiosk design.
* **regions-azs.md** - My reasoning about using a cloud region and multiple Availability Zones for better reliability.
* **iam-least-privilege.md** - A simple example of how an application should only receive the permissions it actually needs.
* **network-topology.md** - My basic design for separating public and private network resources.
