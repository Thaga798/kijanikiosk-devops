# KijaniKiosk Capstone Project – Access Guide

The KijaniKiosk DevOps capstone project is maintained in this repository on a separate feature branch.

### How to access the capstone

1. Open the [KijaniKiosk DevOps GitHub repository](https://github.com/Thaga798/kijanikiosk-devops).
2. Select the branch named **`feature/capstone-infrastructure`** from the branch selector.
3. Open the **`capstone/`** directory to access the project files.

**Direct link to the capstone branch:**

https://github.com/Thaga798/kijanikiosk-devops/tree/feature/capstone-infrastructure

### Project contents

The `capstone/` directory contains:

- Application source code and Dockerfile.
- Kubernetes deployment and service manifests.
- Jenkins CI/CD pipeline.
- Project documentation and reflection.
- Testing, deployment and pipeline evidence.
